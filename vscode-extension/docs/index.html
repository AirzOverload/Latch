Latch 1.0 Alpha

A C-family language experiment where mutation authority is part of the callable contract.

What problem does Latch solve?

Passing a reference to a large object often makes it difficult to know which state a function may change without reading its implementation. Latch separates access from mutation authority. A reference lets code reach an object; a latch(...) contract declares the state that callable is authorized to mutate.
