Core language

Classes and inheritance

public class Entity {
    public virtual string describe() { return "Entity"; }
}

public class Player extends Entity {
    private int health = 100;
    public override string describe() { return "Player"; }
    public void damage(int amount) latch(this.health) {
        this.health -= amount;
    }
}

Single class inheritance and inherited/overridden method lookup execute in this alpha. Access-modifier syntax is accepted; full visibility enforcement is still being implemented.

Access versus mutation

public/private/protected/internal answer who may access a symbol. latch answers which state a callable may mutate. They are intentionally independent.
