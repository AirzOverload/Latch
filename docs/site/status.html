1.0 alpha feature matrix

✓ Executing: classes, fields, methods, new, single inheritance, overriding, functions, loops, if/else, basic arrays, operators, comments, latch(this.member), relative imports, multi-file loading, core output/conversion built-ins.

△ Parsed/design-active: access modifiers, interfaces, abstract/final/static/const/virtual/override metadata.

✗ Not yet production-complete: visibility enforcement, interface dispatch/conformance, constructors and super chaining, lambdas/closures, generics, runtime enums, switch/match, indexed assignment, exception/error types, package/library artifacts, namespaces, full static typing.

Known bug: recursive calls nested inside some binary expressions currently evaluate incorrectly; recursion is therefore not marked supported.

This page exists so documentation cannot quietly turn roadmap syntax into an implementation claim.

Alpha 2 implementation

Constructors, List/Map/Set, foreach, main(args), nested types, recursion, nested control flow, and collection latch checks are executable and tested. True enclosing-instance inner classes, constructor chaining, lambdas, and full generic type checking remain incomplete.
